🧪 Prueba del Sistema de Feedback

ℹ️ Información

Esta página te permite probar el sistema de retroalimentación sin necesidad de subir un proyecto completo.

  • Califica con estrellas (1-5)
  • Agrega comentarios opcionales
  • Los datos se envían al backend
⚠️ Nota: Debes estar autenticado para enviar feedback. Asegúrate de haber iniciado sesión en index.html primero.

Acciones de Prueba:

Flujo Normal en Producción:

  1. Usuario sube proyecto en principal.html
  2. Sistema analiza el código automáticamente
  3. Al completar, muestra la encuesta (2 segundos después)
  4. Usuario califica y/o comenta
  5. Datos se guardan en la base de datos

Ver Resultados:

Los administradores y docentes pueden ver las estadísticas en:

  • GET /api/v1/feedback/estadisticas
  • GET /api/v1/feedback/promedios-por-tipo
  • GET /api/v1/feedback/recientes
